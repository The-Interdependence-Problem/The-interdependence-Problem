# Welcome to the Interdependence Problem Repository!

This repository is an effort in formulating and improving the concept of interdependence, and how that affects life with others. This is a collaborative effort, and participation from all who are interested is welcome. 


Items on the agenda: 

1. The common goal: Acknowledgements, such as the acknowledgement of choice, separation of needs and strategies, the resources problem, Inferential awareness, Verification, Rights vs. Needs, Deservingness, Thought terminating concepts. These are all concepts that I would like to write about.
